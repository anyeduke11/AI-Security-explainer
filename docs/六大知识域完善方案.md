### 1.2 站点现状盘点

| 维度 | 现状 |
|---|---|
| 知识域 | 6 个（llm / mcp / agent / skills / web / infra），均为 OWASP 技术风险清单 |
| 风险条目 | 60 条，每域 10 条，level 分布 18 入门 / 32 进阶 / 10 挑战 |

### 1.3 核心结论

现有 6 个知识域全部是**技术风险清单**（OWASP 系列），而文档第 1～4 章属于 **AI 原理基础、安全基础、社会影响、政策法规标准**，与现有技术域无法自然对应。因此本方案采取「**现有六域扩充 + 新增三个知识领域**」的策略，形成 **9 大知识域**。

## 二、知识域整合总览

### 2.1 映射原则

1. **技术风险归技术域**：文档中的威胁、评估、防护内容按攻击面归入现有 6 域；
2. **基础与治理独立成域**：无法归入技术清单的「原理基础 / 社会影响 / 合规治理」新增领域；
3. **一知识点可跨域标注**：主归属唯一，同时在相关域建立 `seeAlso` 交叉引用（如「越狱」主属 `llm`，`governance` 保留合规视角引用）；
4. **尊重原掌握等级**：文档中的【必须掌握/应掌握/熟悉/了解]直接映射为站点 level 与优先级；
5. **不引入体系外概念**：所有内容严格来自源文档，不自行发挥。

### 2.3 新增知识领域说明

| 新域 id | 名称 | 英文 / 依据 | 收录范围 | 建议 code 前缀 | 初始风险条目数 |
|---|---|---|---|---|---|
| `foundation` | AI 与安全基础 | AI & Security Fundamentals（文档第 1～2 章） | AI/ML/DL 关系、Transformer 原理、训练与微调范式、系统构建、AI 安全定义与属性、六层安全问题、威胁模型与常见攻击 | `FND01`～`FND10` | 10 |
| `society` | 社会与安全影响 | societal & societal impact（文档第 3 章） | 社会安全、经济安全、关键基础设施依赖、军事安全；影响链路三分类（技术失效/恶意使用/结构性变化）、信息环境、公共服务 | `SOC01`～`SOC10` | 10 |
| `governance` | 合规与治理 | policy, standards & assessment reporting（文档第 4 章 + 7.6） | 国家战略（美/欧/中）、法规政策、标准规范（ISO/IEC 42001、23894、IEEE 7000、国内三件套）、合规判定、评估报告 | `GOV01`～`GOV10` | 10 |

**新增理由**：

- `foundation`：现有域假设读者已懂 Transformer/学习范式，但文档用约 1 小时视频讲解这些原理，是「理解后续所有风险」的前置知识，必须独立成域；
- `society`：现有域全是技术攻击面，而文档第 3 章讲「社会/经济/军事影响」，涉及责任主体、治理工具、信息环境，与技术风险正交；
- `governance`：政策法规与评估报告是独立的合规工作流，不属于任何 OWASP 技术清单，且文档标注为高频考点。

### 3.3 内容入库规范

每个新增条目按现有 `R()` 构造器完整填写 14 个字段：

```
R(code, title, en, cat, level, zones,
  brief,        // 30 秒读懂：一句话定义 + 为什么重要
  why,          // 30 秒读懂：风险来源与后果
  steps,        // 原理拆解：['小标题::说明', ...] 至少 3 步
  analogy,      // 打个比方：用源文档案例（如「李逵大闹五台山」）
  demo,         // 动手试一试：type + topic + title
  defense,      // 如何防护：至少 3 条
  scenario,     // 典型场景：源文档真实案例
  quiz)         // 随堂小测：[题干, 选项[4], 正确下标, 解析]
```

**硬性要求**：

1. `brief`/`why`/`steps`/`defense`/`scenario`/`quiz.e` 必须引用源文档的具体表述或案例，不得凭空编写；
2. 掌握等级映射：【必须掌握】→ level 3，【应掌握】→ level 2，【熟悉/了解】→ level 1；
3. 每条内容的 `basis` 字段标注源章节号（如「第 5.2 节 PDF 第 28-32 页」）；
4. 术语首次出现须能被 `GLOSSARY` 的 `pat` 命中，否则同步补充术语条目。

## 四、七种学习形式设计

### 4.1 现状与目标

| 学习形式 | 现状 | 改造目标 |
|---|---|---|
| 知识学习卡片 | **缺失独立形态** | 新增卡片组件，作为知识域与条目的统一入口 |
| 30 秒读懂 | 已有（`brief`/`why`/`analogy`） | 扩充为「一句话定义 + 风险一句话 + 打个比方」三段式 |
| 原理拆解 | 已有（`steps[]`） | 从 3 步扩至 4～6 步，支持源文档的对照表 |
| 动手试一试 | 已有（`demo` + 靶场 `SCRIPTS`） | 新增 3 种演示引擎覆盖基础/治理/社会域 |
| 如何防护 | 已有（`defense[]`） | 按「输入侧/系统侧/出口侧」三层归类展示 |
| 典型场景分析 | 已有（`scenario`） | 增加「案例 → 影响链路 → 治理要点」结构化模板 |

### 4.2 知识学习卡片（新增）

**设计**：在知识域页与风险详情页顶部增加统一的卡片区，每张卡包含：

| 区域 | 内容 | 数据来源 |
|---|---|---|
| 卡头 | 域色条 + code + 标题 + level 徽章 | `CATS.color` / `r.code` / `r.title` / `r.level` |
| 核心定义 | 一句话「是什么」 | `r.brief` |
| 掌握等级 | 源文档等级徽章（必须掌握/应掌握/熟悉/了解） | 新增 `r.mastery` 字段 |
| 来源标注 | 「第 X 章 · PDF 第 Y 页」 | 新增 `r.basis` 字段 |
| 交叉引用 | `seeAlso` 链接到其他域的相关条目 | 新增 `r.seeAlso` 字段 |
| 操作区 | 「30 秒读懂 / 动手试一试 / 随堂小测」快捷跳转 | 锚点 |

**布局**：桌面 3 列网格、移动端单列；卡片支持术语悬浮卡（`gl()`）。

### 4.3 30 秒读懂

在现有 `brief`/`why` 基础上，强制三段式：

1. **一句话定义**（20～40 字）：直接取自文档「是什么」首句；
2. **风险一句话**（20～40 字）：取自文档「记忆点」；
3. **打个比方**：取自文档案例（如「李逵大闹五台山」「自动营业员」「合法傀儡」）。

验收：每个新增条目三段齐全，每段不超过 60 字。

### 4.4 原理拆解

- 每个条目 `steps` 至少 4 步，按「背景 → 机制 → 关键参数 → 边界条件」组织；
- 源文档中的对照表（如四种学习范式、幻觉四类型、标准三件套）转为 `steps` 的「表格型步骤」，新增 `step.table` 字段支持二维数组渲染；
- 每个步骤保留 `gl()` 术语悬浮卡。

### 4.5 动手试一试

现有 8 种引擎（`prompt/scope/pipeline/inspect/budget/rag/web/flow`）复用，新增 3 种：

| 新引擎 type | 用途 | 覆盖域 | 交互设计 |
|---|---|---|---|
| `concept` | AI 基础概念演示（模拟 QKV/注意力、学习范式对比） | `foundation` | 参数滑块 + 可视化输出 |
| `policy` | 合规判定演练（五问判定、标准选用） | `governance` | 情景选择 + 判定反馈 |
| `impact` | 社会影响链路分析（技术失效/恶意使用/结构性变化分类） | `society` | 案例分类拖拽 + 影响链路图 |

新增 `SCRIPTS` 靶场剧本，确保每个新 code 都有对应剧本（否则 Tab 显示「建设中」）。

### 4.6 如何防护

按源文档的「输入侧 / 系统侧 / 出口侧」三层组织 `defense[]`：

- **输入侧**：过滤、校验、schema、围栏（对应文档 8.1/8.3）；
- **系统侧**：最小权限、签名、审计、知识图谱（对应 8.5/8.7）；
- **出口侧**：输出审查、人机回环、熔断降级（对应 8.2/8.6/8.8）。

每条防御措施须能追溯到文档原文，并显示对应章节号。

### 4.7 典型场景分析

统一模板：

```
【案例】源文档真实案例（如 Common Crawl 密钥泄露、LangGraph 7.3 漏洞）
【链路】触发条件 → 攻击面 → 影响范围 → 现实后果
【治理】文档给出的控制措施
【辨析】文档中的辨析点（如「辅助信息 vs 直接触发」「越狱 vs 幻觉哪个更难防」）
```

### 4.8 随堂小测

- 新增 152 条风险各自 1 道随堂题（沿用 `quiz` 字段 4 选项格式）；
- 扩展题库从 500 题按新域重新分类（新增 3 域需补充分配，避免新域无题可练）；
- 测验中心支持按 9 域筛选、按掌握等级筛选；
- 解析中的「依据」统一标注源章节。
